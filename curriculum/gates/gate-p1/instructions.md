Ten minutes, cold: no notes, no hints, no tutor. If it takes longer,
that's fine - but try it straight through first. Retakes are free,
forever, and `reset` deals a fresh board.

Your sandbox contains a small git repository called `workbench/`
with some clutter in it. Standing inside `workbench/`, do four things:

1. **Navigate & organize** - make a directory `logs/` and move every
   `.log` file into it.

2. **Pipe** - count how many lines in `words.txt` contain the word
   `shell`, and put that number (just the number) in a file called
   `count.txt`.

3. **Permissions** - make `greet.sh` executable, and prove it runs:

       ./greet.sh > greeting.txt

4. **Commit** - stage everything and commit with a message that
   includes `gate p1`. Leave the working tree clean.

Then, from anywhere: `python3 codin.py gate p1`

Passing opens Phase 2: Python. Not passing costs nothing - it just
shows you exactly which hand still needs practice.
