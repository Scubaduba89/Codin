Welcome. This platform lives entirely in this repo, and this first
exercise just proves your machine is ready.

1. Run the doctor:

       python3 codin.py doctor

2. Fix anything it flags - it tells you the exact command each time.
   The one it will definitely ask for: give this device a name.

       python3 codin.py doctor --device desktop

   (Call it anything you like. When you set up your phone later,
   you'll name that one too, and the dashboard will show which wins
   happened where.)

3. When the doctor is all green:

       python3 codin.py check setup-01

That's it. Every exercise here ends the same way: you do something
real, `check` verifies it actually happened, and verified work - only
verified work - earns XP.
